📘 30‑Day C++ Study Plan With Daily Practice Tasks

🗓️ WEEK 1 — C++ BASICS
Day 1 — Setup + Hello World
Learn: compiler, IDE, basic structure
Practice:
	• Install VS Code or Visual Studio
	• Write a program that prints your name
	• Modify it to print on multiple lines

Day 2 — Variables & Data Types
Learn: int, float, double, char, bool
Practice:
	• Declare 10 variables of different types
	• Print them in one sentence
	• Convert between types (int → float, etc.)

Day 3 — Operators
Learn: arithmetic, comparison, logical
Practice:
	• Build a simple expression evaluator
	• Compare two numbers and print the larger
	• Create a boolean expression that evaluates to true

Day 4 — If/Else
Learn: branching logic
Practice:
	• Write a program that checks if a number is even/odd
	• Create a grading system (A/B/C/D/F)
	• Build a simple login check (hardcoded username/password)

Day 5 — Loops
Learn: for, while, do‑while
Practice:
	• Print numbers 1–100
	• Print a multiplication table
	• Sum all numbers from 1–n

Day 6 — Functions
Learn: parameters, return values
Practice:
	• Write a function to add two numbers
	• Write a function to check if a number is prime
	• Write a function that prints a pattern (triangle, square)

Day 7 — Review Project
Mini‑Project:
Build a basic calculator with functions for +, −, ×, ÷.

🗓️ WEEK 2 — ARRAYS, STRINGS, POINTERS
Day 8 — Arrays
Practice:
	• Store 10 numbers in an array
	• Find the max/min
	• Reverse the array manually

Day 9 — Strings
Practice:
	• Count vowels in a string
	• Reverse a string
	• Check if a string is a palindrome

Day 10 — Pointers
Practice:
	• Create a pointer to an int
	• Print the value and address
	• Change the value using the pointer

Day 11 — References
Practice:
	• Write a function that swaps two numbers using references
	• Compare pointer vs reference behavior

Day 12 — Dynamic Memory
Practice:
	• Allocate an array using new
	• Fill it with numbers
	• Delete it properly

Day 13 — Vectors
Practice:
	• Add/remove elements
	• Sort a vector
	• Search for an element

Day 14 — Review Project
Mini‑Project:
Build a text analyzer that counts words, characters, and sentences.

Day 15 — Classes & Objects
Practice:

Day 16 — Encapsulation

Day 17 — Inheritance
Practice:

Day 18 — Polymorphism
